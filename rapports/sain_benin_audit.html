🛠️ Recommandations de correction

FIX Actions prioritaires
  1. Configurer les Row-Level Security (RLS) Supabase : Activer les policies SELECT sur toutes les tables. Seuls les utilisateurs authentifiés doivent pouvoir lire les données.
  2. Ne pas exposer la clé anon dans le JS : Utiliser une API gateway ou un proxy pour les requêtes sensibles.
  3. Limiter le Storage : Configurer les policies d'accès aux buckets pour empêcher le listing des fichiers.
  4. Ajouter un rate limiting : Empêcher le scraping massif de la base de données.
  5. Monitoring : Activer les logs Supabase pour détecter les accès non autorisés.
